Version corrective de **Patine 0.1** : une page de chargement remplace la fenêtre blanche du démarrage.

## Installer

| Système | Fichier |
| --- | --- |
| Windows 10 ou 11, 64 bits | `Patine-0.1.2-windows-x64-setup.exe` (installateur) ou `Patine-0.1.2-windows-x64-portable.zip` (sans installation) |
| Linux, 64 bits | `patine-0.1.2-linux-x64.tar.gz` (il faut un pilote Vulkan) |

Installer la 0.1.2 par-dessus une version précédente suffit : vos projets et vos presets ne changent pas.

Les exécutables ne sont pas signés. Si Windows SmartScreen bloque le lancement : *Informations complémentaires*, puis *Exécuter quand même*.

## Nouveautés et corrections

- **Page de chargement.** Avant, la fenêtre restait blanche pendant la préparation de la carte graphique, puis l'interface se figeait le temps de préparer les miniatures de la bibliothèque. La fenêtre s'ouvre maintenant directement sur une page de chargement, environ une demi-seconde après le lancement. Celle-ci indique l'étape en cours, avec une barre de progression : vues, calques, matériaux, environnement, projet. L'interface apparaît quand tout est prêt, miniatures comprises. La fenêtre continue de répondre pendant le chargement, et on peut la fermer à tout moment.

  Durées mesurées sur la machine de développement :

  | API | Durée |
  | --- | --- |
  | Vulkan | environ 1 s |
  | DirectX 12 | environ 4 s |

- **Sélection des triangles sous DirectX 12.** La recherche du triangle sous le curseur utilise de nouveau le chemin rapide sous DirectX 12. Le journal ne contient plus l'erreur de shader qui apparaissait à chaque démarrage.
- **Dépendances.** Une bibliothèque du presse-papiers, retirée de crates.io par son auteur, a été mise à jour.

---

*English.* Bug-fix release. The window opens on a loading page (progress bar and current step) instead of staying white while the GPU work is prepared; the interface shows once everything, library thumbnails included, is ready. Triangle picking uses its fast path on DirectX 12 again, without the shader error in the log.
