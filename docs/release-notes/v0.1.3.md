Version corrective de **Patine 0.1**. Elle corrige un plantage au démarrage introduit par la 0.1.2 : **si vous avez installé la 0.1.2, installez la 0.1.3 par-dessus.**

## Installer

| Système | Fichier |
| --- | --- |
| Windows 10 ou 11, 64 bits | `Patine-0.1.3-windows-x64-setup.exe` (installateur) ou `Patine-0.1.3-windows-x64-portable.zip` (sans installation) |
| Linux, 64 bits | `patine-0.1.3-linux-x64.tar.gz` (il faut un pilote Vulkan) |

Installer la 0.1.3 par-dessus une version précédente suffit : vos projets et vos presets ne changent pas.

Les exécutables ne sont pas signés. Si Windows SmartScreen bloque le lancement : *Informations complémentaires*, puis *Exécuter quand même*.

## Correction

- **Plantage pendant la page de chargement** (0.1.2). Redimensionner la fenêtre pendant le chargement pouvait fermer Patine avec une erreur « Validation Error » (`Surface::configure`). C'est aussi le cas de l'affichage de la fenêtre, qui la redimensionne. Le risque était élevé sur les ordinateurs lents et avec le rendu logiciel (`--gpu software`). Patine attend maintenant le moment où la carte graphique est libre pour adapter la fenêtre.

La 0.1.3 reprend aussi les nouveautés de la 0.1.2 :
- la page de chargement, qui remplace la fenêtre blanche au démarrage ;
- la recherche rapide du triangle sous le curseur, rétablie sous DirectX 12.

---

*English.* Bug-fix release: 0.1.2 could crash at startup ("Validation Error" in `Surface::configure`) when the window was resized during the loading page, which showing the window does, likely on slow machines and with the software renderer. If you installed 0.1.2, install 0.1.3 over it.
