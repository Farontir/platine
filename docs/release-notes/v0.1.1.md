Version corrective de **Patine 0.1**. Sous Windows, sur les PC où Patine passe par DirectX 12, la fenêtre restait blanche longtemps au démarrage. C'est le cas quand la carte graphique n'a pas de pilote Vulkan.

## Installer

| Système | Fichier |
| --- | --- |
| Windows 10 ou 11, 64 bits | `Patine-0.1.1-windows-x64-setup.exe` (installateur) ou `Patine-0.1.1-windows-x64-portable.zip` (sans installation) |
| Linux, 64 bits | `patine-0.1.1-linux-x64.tar.gz` (il faut un pilote Vulkan) |

Installer la 0.1.1 par-dessus la 0.1.0 suffit : vos projets et vos presets ne changent pas.

Les exécutables ne sont pas signés. Si Windows SmartScreen bloque le lancement : *Informations complémentaires*, puis *Exécuter quand même*.

## Corrections

- **Fenêtre blanche au démarrage avec DirectX 12.** Sans compilateur de shaders moderne, DirectX 12 compilait les shaders avec FXC, un compilateur ancien et très lent : l'application restait figée une minute ou plus, la fenêtre blanche. Patine est maintenant livré avec le compilateur DXC de Microsoft (`dxcompiler.dll`, open source). Mesuré sur la même machine, avec un mesh ouvert :

  | API | 0.1.0 | 0.1.1 |
  | --- | --- | --- |
  | DirectX 12 | 59 s | 6 à 9 s |
  | Rendu logiciel | 113 s | 23 s |

- **Journal sur disque.** Chaque session écrit son journal dans `%APPDATA%\Patine\logs\patine.log`, et le journal de la session précédente reste dans `patine.previous.log`. Les erreurs fatales et les plantages y sont consignés, et la boîte d'erreur indique son emplacement. Joignez ce fichier à vos signalements.
- **Choix de l'API graphique.** L'option `--gpu auto|vulkan|dx12|software` contourne un pilote défaillant ; `software` utilise le rendu logiciel de Windows, lent mais indépendant du pilote.
- La désinstallation ne laisse plus de clé de registre `.patine` vide.

---

*English.* Bug-fix release. On Windows PCs that run Patine on DirectX 12 (no Vulkan driver), the window stayed white for a minute or more at startup while FXC compiled the shaders; Patine now ships Microsoft's DXC compiler. Each session writes a log file to `%APPDATA%\Patine\logs\patine.log`, and `--gpu auto|vulkan|dx12|software` picks the graphics API.
